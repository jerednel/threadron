# Acquisition System

## Daily Loop

1. Find 10 people talking about coding agents, AI PR review, generated-code debt, worktree orchestration, or engineering workflow drift.
2. Add the 5 strongest prospects to the pipeline.
3. Reply publicly with a concrete one-sentence take when there is a useful opening.
4. Send the short audit DM to anyone who shows direct team pain.
5. Move each prospect through: New, Replied, DM sent, Call booked, Audit, Sprint, Retainer, Lost.

Pipeline app:

> https://jerednel.github.io/agentops-fieldkit/operator.html

The app stores prospects in browser localStorage so it can run without a backend while the offer is still being validated.

## Prospect Scoring

Strong signals:

- team already uses more than one coding agent
- someone mentions reviewing AI-generated PRs
- worktrees, background agents, or branch sprawl are visible
- engineering leader cares about process, security, or code ownership
- there is a clear weekly cost in review time, rework, or context recovery

Weak signals:

- solo curiosity
- generic AI enthusiasm
- no repo or team context
- only wants tool recommendations
- cannot name a painful failure mode

## Call Outcome

Every call should end with one of three outcomes:

- no pain, no follow-up
- $950 audit
- $4,500 sprint with audit credited

Avoid unpaid custom consulting. If the pain is real enough to diagnose deeply, it is real enough to pay for the audit.
