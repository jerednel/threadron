## First 10 Posts

1. Coding agents do not mostly fail because they are dumb. They fail because the work record is missing.
2. A long agent run should leave a receipt: goal, repo state, files touched, commands run, failed checks, final diff, and next safe step.
3. Worktrees are the cheapest way to make parallel coding agents less chaotic.
4. The next useful AI coding metric is cost per verified outcome, not tokens per second.
5. Shared memory is not operating state. The work record needs ownership, freshness, and deletion rules.
6. Agent review should cite a file, a line, a claim, and a failing case when possible.
7. If the agent cannot explain where it stopped trusting context, it is probably carrying stale confidence.
8. A useful AI coding workflow makes deletion easier, not just generation faster.
9. The second week of agent usage is where the real product starts.
10. I am taking a few teams through a 7-day AgentOps Fieldkit sprint: receipts, shared state, worktree lanes, review gates, and cost routing.
