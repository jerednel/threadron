# Outreach

## Ideal Prospects

Look for engineering leaders and founders saying any of:

- "everyone is using Cursor now"
- "we are trying Codex/Claude Code"
- "AI PRs are hard to review"
- "agent branches are messy"
- "we need evals for coding agents"
- "our team is experimenting with AI coding"
- "generated code is creating maintenance debt"

## Call Questions

1. Which coding agents are engineers actually using today?
2. Where does the workflow get hard to inspect?
3. What is the worst agent-generated change that reached review or production?
4. How do agents hand work between sessions, machines, and people?
5. How do you know a long agent task is done enough to stop?
6. What would you trust more: a dashboard, a PR receipt, or a run ledger attached to the branch?
7. What would this need to save or prevent to justify $1,750/month?
